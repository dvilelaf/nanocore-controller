# Hardware verification

What has been run against a real NANOCORE, what has not, and how to run the rest. The pedal used belongs to the developer; its preset 7 ("TightRhy") was the active preset for the live tests. Unit tests never touch hardware: they use `FakeSession` and `PedalSession` (`src/nanocore_controller/session.py`, `tests/support.py`).

## Not verified on hardware

1. **Writing the other global settings** (Bluetooth of the pedal, loopback, USB and Bluetooth volume, MIDI channel): only the input gain has been written on a pedal.
2. **Whether 48 kHz and a peak of 1.0 are what the pedal expects from an IR** converted from a WAV (the official app's conversion is unknown).
3. **Other firmware versions.** The mapping table is measured on one pedal; the web editor hides the parameters of a block whose parameter count differs from the table.
4. **Browsers other than Chrome and Firefox.**

## Running the missing checks

Each step changes the live state of the active preset and some store permanently. Use a preset you do not mind losing, keep the backup files and stop if anything looks wrong on the pedal.

```bash
# 1. save_active: no change to the stored content when the live state equals it
nanocore --transport usb save --safety-backup /tmp/before-save.json
# then recall another preset and come back: the preset must be unchanged

# 2. restore_active
nanocore --transport usb backup /tmp/preset.json
nanocore --transport usb restore /tmp/preset.json --apply --safety-backup /tmp/before-restore.json

# 3 and 5. the server and the editor, with autosave on a scratch preset
nanocore --transport usb serve        # open the printed address in a browser (Node 22 is only needed to build)
# move a control: the pedal must change at once; stop touching it: after about 3 s the
# indicator must say "saved"; recall another preset and come back: the change must be there.
# The previous content is in $XDG_DATA_HOME/nanocore-controller/baselines/slot-NNN/.

# 4. Bluetooth
nanocore serve --transport bluetooth  # close the phone app first
```
